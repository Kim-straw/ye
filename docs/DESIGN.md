# 설계 문서

## 1. 전체 흐름

```
[폰 브라우저/설치된 앱] --요청--> [FastAPI: main.py] --계산--> [logic.py]
          ^                              |                         |
          |                              v                         v
          +------ HTML / JSON <---- [Jinja2 템플릿]     [SQLite: app.db (db.py)]
```

- 사용자 구분: 로그인 대신 쿠키(`user_id`)를 사용합니다. MVP 한정입니다. 쿠키 값을 바꾸면 다른 사람 프로필이 보이므로 **실서비스 전에 반드시 로그인(학교 메일 인증)으로 교체**해야 합니다.

## 2. ERD

```
schools ─< departments ─< department_tags >─ tags
   │                                          │
   ├─< users ─< user_tags >───────────────────┤
   │     └─< user_specs >─ specs              │
   │                         │                │
   └─< opportunities ─< opportunity_tags >────┘
         ├─< opportunity_specs >─ specs
         └─< reviews
jobs ─< job_requirements >─ specs
```

- `opportunities`: 교내 프로그램과 대외활동을 한 테이블에 둡니다(`scope` = 교내/외부).
- `job_requirements`: 합격자 스펙 대신 **채용공고 자격요건**을 기준으로 합니다(출처가 명확하도록 `source_url`).
- `schools`: 다른 학교 확장용. 지금은 1행.

## 3. 규칙

### 추천 점수
| 항목 | 점수 |
|---|---|
| 겹치는 관심 태그 1개 | +10 |
| 교내 프로그램 | +5 |
| 마감 14일 이내 | +3 |

마감 지난 활동, 겹치는 태그가 0개인 활동은 제외합니다.

### 갭 분석
요건마다 `충족 / 부족(점수 미달) / 없음` 판정 → 필수 요건 충족률 계산 → 미충족 스펙은 `opportunity_specs`로 연결된 활동을 교내 우선으로 최대 3개 추천.

### AI(LLM)를 붙일 수 있는 지점
1. 공고 본문 → 태그 자동 추출
2. 채용공고 원문 → 자격요건 자동 추출
3. 갭 분석 결과 → 학기별 계획 문장 생성
4. 후기 요약

## 4. 6단계: 선배 정보 마일리지 설계안 (코드 미구현)

### 흐름
```
선배: 합격 후기 작성 → [검수 대기] → 관리자 승인 → +100 마일리지
후배: 후기 목록(회사·직무·연도만 보임) → 열람 클릭 → -30 마일리지 → 전문 열람
      (한 번 연 후기는 다시 차감 없음)
신규 가입: 기본 30 마일리지 (첫 열람 1회 가능)
```

### 추가 테이블
```
career_posts      id, user_id, company, job_name, year, spec_summary(구간화), content, status(대기/승인/반려)
mileage_logs      id, user_id, amount(+/-), reason, post_id, created_at   ← 잔액은 이 기록의 합계
post_unlocks      user_id, post_id  (PK 두 개 묶음: 중복 차감 방지)
```
잔액을 `users.mileage` 숫자 하나만 바꾸지 않고 **기록(log)을 남기는 이유**: 은행 통장처럼 입출금 내역이 있어야 오류·부정 사용을 추적할 수 있습니다.

### 위험과 대응
| 위험 | 대응 |
|---|---|
| 신원 특정 (학점+학과+연도+회사) | 학점은 구간(3.5~4.0), 같은 회사·연도 글이 3개 미만이면 학과 비공개 |
| 허위 합격 후기 | 학교 메일 인증 필수, 합격 증빙(이름 가린 캡처)은 관리자만 보고 승인 후 즉시 삭제, 신고 3회 시 비공개 + 마일리지 회수 |
| 저작권 (외부 후기 복사) | 작성 시 "본인 작성" 동의, 외부 사이트 문장 복사 금지 약관 |
| 현금 거래 | 마일리지 구매·양도 기능을 만들지 않음 |
| 마일리지 부족으로 정보 격차가 다시 생김 | 후기 작성 외에 교내 프로그램 후기 작성(+10)으로도 적립 가능하게 |
